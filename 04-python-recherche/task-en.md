# Understanding Python

## Your goal

Find out where Python is used and how written code becomes a running program. Record your findings in `recherche.md` in your own words. Short bullet points or a small comparison table are enough.

## Task

1. Name three areas where Python is used. For each, add a concrete example of something a program could do in that area.
2. Explain the difference between a compiler and an interpreter.
3. Give one typical advantage and one typical disadvantage of each approach. Consider, for example, changing a program, execution speed or requirements for running it. Avoid claims using “always” or “never”.
4. Look at this familiar command:

   ```bash
   python3 systembericht.py
   ```

   Which part is the program that runs your script, and what role does `systembericht.py` play? Explain the command in one or two sentences.
5. Add links to the sources you used.

## Sources to get started

- [Python.org: Applications for Python](https://www.python.org/about/apps/): Skim the headings. Choose three areas and read only their short introductions; you do not need to learn the listed libraries.
- [Python Course: Execute a Script](https://python-course.eu/python-tutorial/execute-a-script.php): Read only “Differences between Compilers and Interpreters” near the bottom, including the two short definitions under “Compiler” and “Interpreter”.
- [Python documentation: interpreted](https://docs.python.org/3/glossary.html#term-interpreted): Read only this glossary entry. It also helps you compare typical advantages and disadvantages.

Interpretation and compilation can be combined. CPython, the usual Python implementation, also translates code into an intermediate form first. You do not need to explain bytecode or virtual machines.
