## 2. Compiler vs. Interpreter

1. Compiler: Translates source code into another form, often an executable program, before running it.

2. Interpreter: Runs program instructions using an interpreter.

## 3. Advantages and Disadvantages

### Compiler
- Advantage: Compiled programs often run faster.
- Disadvantage: After changing the code, recompilation may be needed.

### Interpreter
- Advantage: Code can be changed and tested quickly.
- Disadvantage: Execution can be slower than compiled code.

## 4. Understanding the Command

`python3 systembericht.py`

- `python3` starts the Python interpreter.
- `systembericht.py` is the Python script that contains the instructions.

The interpreter reads and executes the script.
