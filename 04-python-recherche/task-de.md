# Python verstehen

## Dein Ziel

Finde heraus, wofür Python eingesetzt wird und wie aus geschriebenem Code ein laufendes Programm wird. Halte deine Ergebnisse in `recherche.md` in eigenen Worten fest. Kurze Stichpunkte oder eine kleine Vergleichstabelle reichen aus.

## Arbeitsauftrag

1. Nenne drei Einsatzgebiete von Python. Ergänze jeweils ein konkretes Beispiel dafür, was ein Programm dort erledigen könnte.
2. Erkläre den Unterschied zwischen einem Compiler und einem Interpreter.
3. Nenne für beide Ansätze jeweils einen typischen Vorteil und einen typischen Nachteil. Denke zum Beispiel an Änderungen am Programm, Ausführungsgeschwindigkeit oder Voraussetzungen zum Starten. Vermeide Aussagen mit „immer“ oder „nie“.
4. Schau dir diesen bekannten Befehl an:

   ```bash
   python3 systembericht.py
   ```

   Was ist dabei das Programm, das dein Skript ausführt, und welche Rolle hat `systembericht.py`? Erkläre den Befehl in ein bis zwei Sätzen.
5. Ergänze die Links deiner verwendeten Quellen.

## Quellen zum Einstieg

- [Python.org: Applications for Python](https://www.python.org/about/apps/): Überfliege die Überschriften. Wähle drei Bereiche und lies jeweils nur den kurzen Einstieg; du musst die genannten Bibliotheken nicht kennenlernen.
- [Python-Kurs: Compiler und Interpreter](https://www.python-kurs.eu/python3_skript_ausfuehren.php#compiler-und-interpreter): Lies nur diesen Abschnitt bis zur Überschrift „Hilfe“.
- [Python-Dokumentation: interpreted](https://docs.python.org/3/glossary.html#term-interpreted): Lies nur diesen Glossareintrag. Er hilft auch beim Vergleich der typischen Vor- und Nachteile.

Interpretation und Kompilierung können kombiniert werden. Auch die übliche Python-Implementierung CPython übersetzt Code zunächst in eine Zwischenform. Du musst dafür weder Bytecode noch virtuelle Maschinen erklären.
